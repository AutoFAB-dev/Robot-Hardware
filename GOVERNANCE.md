# Governance
This is the open-hardware repository for the AutoFAB cell. AutoFAB software is closed source. Issues and build reports are welcome. Pull requests are **by invitation** for now.

## Issues
We read issues when a maintainer is available. There is no promised response time.

## Pull requests
Invited PRs are reviewed for licence, safety, attribution and `tools/check.sh`. Nothing reaches `main` except through a reviewed PR. No direct pushes to `main`.

Maintainer-owned files (`.github/`, `AGENTS.md`, `LICENSE`, `LICENSES/`, `tools/`) need a maintainer's approval in the issue or PR.
