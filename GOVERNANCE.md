# Governance
This repository is **community-supported**. AutoFAB maintainers review outside work as time allows. There is no promised response time.

## Review and merge
1. Outside changes arrive as a pull request against `main` ([CONTRIBUTING.md](CONTRIBUTING.md)).
2. A maintainer reviews for licence, safety, attribution and `tools/check.sh`.
3. Nothing reaches `main` except through a reviewed PR. No direct pushes to `main`.
4. Maintainer-owned files (`.github/`, `AGENTS.md`, `LICENSE`, `LICENSES/`, `tools/`) need a maintainer's approval in the issue or PR.

## Response expectations
- Issues and PRs are triaged when a maintainer is available. That may take days or longer.
- Security reports: [SECURITY.md](SECURITY.md). Conduct reports: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
