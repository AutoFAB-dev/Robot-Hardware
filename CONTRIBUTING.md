# Contributing
Issues and build reports are welcome. Pull requests are **by invitation** for now.

These rules apply to people and AI agents alike (agents also read [AGENTS.md](AGENTS.md)). Please follow the [Code of Conduct](CODE_OF_CONDUCT.md). How work is reviewed: [GOVERNANCE.md](GOVERNANCE.md).

## Issues
Open an issue for build reports, printer notes, or problems in the docs or hardware. Use the templates.

## Pull requests
Don't send a PR unless a maintainer invited it. If we invite one: start from `main`, use the PR template, and run `tools/check.sh`. Nothing reaches `main` except through a reviewed PR.

## Upstream parts
Fixes to the ElRobot arm go to [norma-core](https://github.com/norma-core/norma-core); fixes to the rail design go to [leslider](https://github.com/pham-tuan-binh/leslider).

## Never
Post passwords, setup-card details, claim codes, tokens, personal information, or photos showing them.
